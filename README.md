# Summative-Lab-Part-1-JavaScript-Calculator

This project contains a simple JavaScript calculator program that:

- Adds, subtracts, multiplies, and divides two numbers
- Stores each successful calculation in a history log
- Displays the history when requested
- Clears stored history when requested

## Run the program

Make sure Node.js is installed, then run:

```bash
node calculator.js
```

## Features

- Menu-driven command-line interface
- Input validation for numeric values
- Protection against division by zero
- Calculation history stored during the program session
- Option to clear calculation history during the program session

## Menu options

When the program runs, you can choose:

```text
1. Add
2. Subtract
3. Multiply
4. Divide
5. Display history
6. Clear history
7. Exit
```

## Example history entry

```text
8 + 2 = 10
```
